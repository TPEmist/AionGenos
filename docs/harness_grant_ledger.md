## Pattern observation — the ledger is a gap map

The four human-eye interventions to date all share one signature: a **jump
from low-level signals to a structural conclusion** that the system could not
make from the numbers alone.

1. **Headless vs windowed** — the silent while-loop "looked like a hang"; the
   user's "拿掉 headless 能跑" read the structural cause the logs hid.
2. **Gripper** — camera-RGB-only + PyG-ABI concerns surfaced by cross-layer
   judgement, not a single metric.
3. **Scene geometry** — "red block looks closer but the arm extends forward"
   caught a marker/target mismatch the magnitude-ranked error vector misread.
4. **Standby pose** — the necessity + configuration judgement that closes the
   9-round reachability saga.

Each is a **cross-layer abstraction judgement**: raw signals → structural
conclusion, a leap the system's current capability boundary cannot yet make.
That is precisely what this ledger maps. **Every ledger entry marks a place
where a human currently supplies the abstraction; each reclamation condition
is the research program that would move that boundary.** The Ledger is the gap
map of the system's present limits.
